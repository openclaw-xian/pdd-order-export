# DOM 契约（订单查询 / 批量导出）

> 环境：Windows + ego lite 0.6.3.14，2026-11-20 在枝枝家居实测。

## 1. 页面入口

- URL：`https://mms.pinduoduo.com/orders/list?tab=0`（`tab=0` = 全部订单(近3个月)）
- 标题：`订单查询`
- 店铺名：`.user-name-text` / `.user-name-name`（右上角，如 `枝枝家居`）
- 页签：全部订单(近3个月) / 待付款 / 待发货 / 待收货 / 退款售后 / 3个月前订单

## 2. 筛选区

- 订单状态、售后状态：默认「全部」；超时状态默认「不限」
- 商品 ID/订单编号/收件人/快递单号等留空
- `订单下单时间`：下拉（近7/30/90日、自定义等）+ 只读日期范围输入

## 3. 日期范围控件（RPR）

- 输入：`input[placeholder="请选择日期"][readonly]`（`data-testid="beast-core-rangePicker-htmlInput"`）
- **打开方式**：用真实鼠标点输入框（ego `page.mouse.click`），普通 `page.click` 不一定弹；有时第一次点不弹、第二次才弹 → 循环点 + 检测 `div[class*='RPR_outerPickerWrapper']`
- 面板：
  - 双月：左 `RPR_headerSelector`（`2026年` + `10月`）、右同理
  - 箭头：`svg[class*='RPR_iconPrevNext']` + `RPR_right`；点箭头经常会**关闭面板**，但月份已经变了 → 必须重新打开再回读
  - 日期格：`td[class*='RPR_tdDay'] > div[class*='RPR_cell']`；非本月/不可选带 `RPR_outOfMonth` / `RPR_disabled`
  - 底部：两个只读 `请选择时间`（`data-testid=...timePicker-htmlInput-begin/end`）、`归零`、`确认`
- `归零`：把起止时间都设为 `00:00:00`
- `确认`：必须点，否则日期不会写回筛选区
- 时间三列（小时/分/秒）是虚拟滚动列表；本 skill 不使用它（统一归零 + 结束日 +1 天）

## 4. 日期语义（坑）

- 结束时间 `00:00:00` **不含结束日**（左闭右开）
- 实测：
  - `10/01 00:00 ~ 10/31 00:00` → 1433 单（只到 10/30）
  - `10/01 00:00 ~ 11/01 00:00` → 1488 单（完整 10 月）
  - `10/31 00:00 ~ 11/01 00:00` → 55 单（正好是 10/31）
- 所以目标止日必须 +1 天；日期回读格式 `YYYY-MM-DD 00:00:00 ~ YYYY-MM-DD 00:00:00`

## 5. 查询计数

- 查询按钮：文本「查询」
- 结果：`共查询到 N 个订单`；分页底部另有 `共有 N 条`

## 6. 批量导出

- 按钮：文本「批量导出」
- 弹窗：`批量导出订单`（`MDL_modal`），显示当前日期范围、筛选摘要、导出时间
- 报表类型：`自定义报表` / `对账报表`（默认选中对账报表；含订单/商品/金额字段）
- 按钮：`查看已生成报表`、`生成报表`
- 点「生成报表」→ **新开标签页** `https://mms.pinduoduo.com/orders/exportExcel?exportType=0`
- 导出页：标题 `订单查询/已生成报表`，有 `下载报表` 按钮
- 平台限制（弹窗原文）：
  - 拼单成功时间间隔 ≤3 个月
  - 两次导出间隔 ≥5 分钟
  - 任务保留 24 小时

## 7. 下载

- 点「下载报表」→ 浏览器标准下载到 `%USERPROFILE%\Downloads`
- 文件名：随机前缀 + `orders_exportYYYY-MM-DD-HH-MM-SS.csv`（实测 `a5b385...orders_export2026-11-20-14-17-47.csv`）
- 编码：UTF-8 BOM
- 下载后文件可能仍被浏览器占用 → 必须等大小稳定再复制，不能直接 rename

## 8. CSV 列（对账报表）

`商品, 订单号, 订单状态, 商品总价(元), 邮费(元), 店铺优惠折扣(元), 平台优惠折扣(元), 多多支付立减金额(元), 用户实付金额(元), 商家实收金额(元), 商品数量(件), 发货时间, 确认收货时间, 商品id, 商品规格, 样式ID, 商家编码-规格维度, 商家编码-商品维度, 商家备注, 售后状态, 快递单号, 快递公司, 订单成交时间, 是否分期, 分期期数, 手续费承担方, 分期方式`
