# 方法、用法与踩坑（pdd-order-export）

## 1. 方法

| 目标 | 方法 |
|---|---|
| 选订单范围 | `/orders/list?tab=0` 全部订单；状态全部 |
| 选日期 | RPR 日期面板：翻月 → 点起止日 → 归零（00:00:00）→ 确认 |
| 日期语义 | 结束 00:00 不含当天 → **结束日 = 目标止日 +1 天** |
| 查单量 | 查询 → `共查询到 N 个订单` |
| 导出 | 批量导出 → 对账报表 → 生成报表 → 新页 → 下载报表 |
| 归档 | Downloads 取最新 `orders_export*.csv` → 改名 `<店铺>-订单-<月>月.csv` → 写 `订单信息.md` |

## 2. 怎么用

```bash
node run.mjs order-config.json
# {"from":"2026-10-01","to":"2026-10-31","shops":[{"shop":"店铺A","profile":"profileA"}]}
```

- 默认串行；月度多店逐店跑
- 区间不能超过 3 个月；两次导出间隔 ≥5 分钟

## 3. 踩坑

| 现象 | 根因 | 正确做法 |
|---|---|---|
| 10 月少 55 单 | 结束日 00:00 不含当天 | 结束日 +1 天（10/31 → 11/01） |
| 日期输入框点不开 | 需要真实鼠标事件/点击两次 | `page.mouse.click` + 检测 RPR wrapper，循环重试 |
| 点箭头后月份变了但面板关了 | 组件行为 | 重新打开面板，回读 header 月份再继续 |
| 选了日期但查询没变 | 漏点「确认」 | 选完必须点确认并回读输入框 |
| 生成报表没反应 | 按钮在弹窗里，可能还没启用；或 5 分钟导出限制 | 等按钮可用；检查导出间隔 |
| 下载文件 EBUSY | 浏览器仍在写/持句柄 | worker 先 `task.finish` 关页释放句柄，再等大小稳定 copy；失败重试 |
| 归档目标 EBUSY | 目标 CSV 被 Excel/WPS 打开 | worker 自动改写为 `.new-<时间>.csv`，`订单信息.md` 记录实际文件名 |
| 生成报表无新页 | 两次导出间隔 <5 分钟 | worker 识别 `rate_limited`；等 5 分钟再跑 |
| 首次无 `_stores.json` | 需要店铺名单 | runner 自动扫 ego profiles 生成（`STORES_DISCOVERED`） |
| 多店同时导出拿错文件 | Downloads 共享 | 串行执行，每店单独跑 |
| 在待发货页签上跑 | 默认页签可能不是全部订单 | worker 强制校验 `tab=0` 并点「全部订单」 |
| 状态筛选不是全部 | 用户/上次操作改了筛选 | worker 校验 2 个「全部」+「不限」，否则 `status_filter_not_all` |
| 页面加载失败仍退出 0 | — | 失败退出码 5；needs 4；预检 3 |
| CSV 乱码 | 用 GB18030 读 | 实际 UTF-8 BOM；按 utf-8-sig 读 |

## 4. 边界

- 当前仅支持「全部订单(近3个月)」；3 个月前订单/更早日期未实现
- 跨年月份切换未单独验证
- 平台要求两次导出间隔 ≥5 分钟；任务 24h 内可重下
- 下载走系统 Downloads；不保证无头/无下载目录环境
